🔗 Webhook TikTok

L'endpoint POST /api/gift reçoit les cadeaux envoyés pendant le live TikTok.

📦 Format de payload

Les champs sont flexibles — TikTok peut envoyer différentes variantes : 
{
  "senderNickname": "PseudoViewer",
  "giftType": "Rocket",
  "giftCount": 1
}

📝 Champs acceptés

senderNickname / senderName / sender / nickname giftType / giftName / gift.name giftCount / count / quantity

🎮 Correspondance cadeau → points

Les valeurs sont converties automatiquement : 
Rose 🌹 = 1 pt
Cœur 💕 = 5 pts
Câlin 🤗 = 10 pts
Panda 🐼 = 50 pts
Rocket 🚀 = 100 pts
Galaxie 🌌 = 250 pts
Crown 👑 = 500 pts

✅ Test local

curl -X POST http://localhost:3000/api/gift \
  -H "Content-Type: application/json" \
  -d '{"senderNickname":"Test","giftType":"Crown","giftCount":2}'

🌐 En production

Une fois déployé, l'URL sera https://TON_DOMAIN/api/gift.
Configure-la dans l'espace développeurs TikTok dans la section "Webhooks".

⚠️ Conditions

  • Le serveur doit être accessible depuis TikTok (pas de blocage réseau).
  • Utilise GET pour voir une erreur 404 (c'est normal).
  • Utilise POST pour envoyer un cadeau et déclencher les dégâts.
